SRC-063 implements the first Report Builder slice: versioned object/field/relation/metric/model descriptors, authorized metadata views and strict report-definition validation. [Contract](../../docs/contracts/reporting-semantic-kernel.md) and [plan](../../docs/planning/report-builder.md).

Exports `catalogV1`, `createRegistry`, `visibleCatalog`, `compileDefinition` and definition types/schema. Callers supply trusted native authorization context and a tenant-scoped datasource binding; there is no fallback tenant or default binding. Successful compilation returns `kind: semantic_only`, pinned semantics, required fields, per-grain partitions and a fingerprint. It does not query data or authenticate the context.

Supported first-slice encodings: table, KPI, bar, line, pivot. Built-in acquisition and separate base/age/region Insights models prevent unsafe demographic/media joins. Connected data availability is supplied by the binding; registration is not evidence of ingestion.

SRC-057 adds an independent NestJS private HTTP entrypoint, own MySQL draft/version store and native CRM BFF with real Identity own/all ACL. Six business tables plus journal preserve catalog snapshots, immutable edits, CAS/idempotency, audit and outbox facts. [Storage contract](../../docs/contracts/reporting-persistence.md), [OpenAPI](../../docs/contracts/reporting-storage.openapi.json), [local runbook](../../docs/development/reporting-storage.md). Draft storage does not run the semantic compiler or authorize source fields; every saved result is explicitly unvalidated and nonexecutable.

Build: `pnpm --filter @agentic-crm/reporting build`. Unit tests from repository root: `pnpm exec vitest run services/reporting/tests`. MySQL and native HTTP: `node scripts/reporting-storage-test.mjs`, `node scripts/reporting-native-test.mjs` after local test provisioning. Use the repository-pinned Node24 runtime. No dashboard UI, query API/worker or publish path exists; SRC-059 remains IN_PROGRESS and SRC-060…062 remain later scoped gates. No service is automatically started by provisioning.
