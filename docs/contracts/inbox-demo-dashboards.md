## Metrics and ownership

Reporting-owned synthetic catalog adds registered models: inbox_operations (one episode), inbox_activity (one handling event), agent_workload (one agent/shift), ad_inbox_quality (one Ad/shift). Every descriptor has strict typed fields, dependency/coverage/execution registrations and immutable model/metric versions. Existing G1 catalogs/execution hashes remain unchanged; extension is present only in this scenario snapshot. Native report query authorization remains report_definition.run/all + report_mock_source.read/all. No connected producer access is inferred.

Indicators are derived from scenario state/events, not injected result totals. Distinct session counts; conditional count via0/1inputs; first-response and accept delay computed from explicit event times, nullable for unanswered/unaccepted. Means/p50/p95 exclude missing values and display their population. Current queue age is as_of minus arrival for the20queued only; customer-silent after outbound is a separate5-session category. SLA120seconds is an explicit demo assumption; report first replies meeting SLA over all50inbound and over30responded as separate metrics. Activity chart buckets actual simulated inbound/accept/first-send event times into15-minute slots; it is not acquisition-cohort throughput. Agent workload excludes5closed spam; occupancy=sumactive/sumslots and productivity=sumaccepted/sumstaffed_hours. Ad cost-per-Lead=sumspend/sumleads, null when denominator0; rate totals always recomputed, never average subgroup ratios.

## Private dashboard contract and UI

Reuse Reporting's existing tenant-scoped private report_definition/report_version/receipt/audit storage, which already accepts bounded unvalidated JSON. No new table/schema/migration. A version1 dashboard document has kind=dashboard, description, up to12ordered widgets, each with id/title/note, immutable snapshot generation and a full validated report definition. No results/cookies/ACL snapshots stored inside the dashboard. Private ownership/read/design/CAS/idempotency and native CSRF remain unchanged. Save is still private/unvalidated metadata; execution always compiles and authorizes each report against its pinned catalog/generation. No publication or viewer sharing is implied. Dimensionless table widgets show a KPI summary strip plus the exact table; the existing single-metric KPI report encoding is unchanged.

Report Builder library opens either a report or dashboard after a strict shape check. Dashboard view renders KPI cards, charts and tables using existing renderers; per-widget notes include population/units/coverage. Manual Refresh runs at most2queries concurrently (existing query-service limit), clears old results first, rejects stale responses after tenant/identity/document changes, and clears all results on authorization failure. Other widget failures are explicit partial errors, never zero. Save/edit supports dashboard name/description, widget title/note/order/removal, adding currently configured reports with their generation, and existing CAS conflict behavior. Both requested dashboards are persisted and reopened. Pinned snapshots provide reproducibility; no claim of automatic live refresh. Mobile layout and accessible exact data tables required.
