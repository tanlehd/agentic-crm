# Registry foundation — SRC-010

Status: Ready for implementation. Bổ sung [API](api.md), [CRM](../modules/crm.md), [physical schema](../data/physical-schema.md).

SRC-010 expose GET/POST object-types, GET/POST association-types, POST associations và GET records/{id}/associations. Record CRUD/property/index/form/view tiếp tục SRC-011/012. Public assignment và domain cancellation/routing tiếp tục SRC-017. Không tạo Deal/Ticket qua generic API.

Metadata collection dùng pagination chuẩn limit 50/max100, signed cursor bind account/tenant/route và position created_at,id. Object output: id,tenant_id,key,label,kind,version,schema_version; version/revision là decimal string. Create {key,label} chỉ custom, standard keys và permission namespaces (schema/association/membership/role/team/agent/automation/integration/audit) reserved. Association type input {key,source_type,target_type,label,cardinality}; source_type/target_type là object key, output thay bằng source_object_type_id/target_object_type_id và version. Metadata immutable trong scope này; không PATCH.

Association input {type_key,source_record_id,target_record_id}; If-Match bắt buộc là version source. Cần association.create/all, read cả hai đầu, update source; không read trả404, thiếu update/action trả403. Lock hai record theo ID tăng dần, kiểm object type, active và cardinality. one_to_many: target tối đa một source; one_to_one: cả source và target tối đa một đầu đối ứng. Duplicate pair trả409 ALREADY_EXISTS; cùng receipt replay trả201. Create tăng source version, không tăng owner_revision. Output id,tenant_id,association_type_id,source_record_id,target_record_id,source_version. GET association list gồm cả incoming/outgoing, chỉ association đọc được hai đầu; pagination trên tập visible, không leak hidden count/cursor/label. Replay luôn kiểm read hiện hành hai đầu.

Schema grants read/create/update scope all cần configure. Association.read/all cần read capability; create/all cần một trong chat/sales/service (viewer không write). Registry record access dùng chính object key; read cần read capability, create/update/assign cần một trong chat/sales/service. Role và own/team/all vẫn bắt buộc; schema.read không cấp record read. Deal/Ticket không được module registry mở hành vi nghiệp vụ. Persisted field policy tải bằng role IDs từ Identity port; deny read kéo theo filter/export.

Internal registry port chạy trong UnitOfWork của module gọi. Chỉ subtype adapters đăng ký trong composition được create/update/assign; adapter insert+exists xác nhận đúng subtype trong cùng transaction. Không cài adapter production giả ở SRC-010. Create ghi initial history revision1; mutation CAS version; assignment tăng version và owner_revision, ghi history và record.assigned atomic. Actor được xác thực qua Identity port; owner active Human/AI cùng tenant, team active, target phải thuộc team khi có team. Eligibility/domain guards do adapter bắt buộc kiểm tra; service không làm owner. Reason event là mã kỹ thuật allowlisted, không nhận free text/PII vào outbox. History append-only runtime DB grants.

Fixture extension registry v2 tạo bảy standard types cho Alpha/Beta bằng CLI local riêng, transaction atomic, advisory lock. Marker system audit là completion marker; rerun kiểm IDs/type keys, giữ label/version/ACL đã sửa; thiếu fixture fail closed. Không regrant Identity roles; muốn thao tác schema qua HTTP dùng Identity role admin API đã có. Field policy chưa public editor. Không seed record/subtype trước task tương ứng.

Migration v6 giữ nguyên checksum v1–v5, forward-only. Upgrade giữ Identity/seed và volumes; app chỉ ready khi schema manifest đầy đủ.

M1 HTTP mutations serialize trên tenant exclusive lock với Identity/config và receipt writes, rồi lock endpoint IDs theo thứ tự; internal registry ports giữ shared authorization lock và row CAS. Chưa tối ưu throughput cùng tenant. Create port ghi registry/subtype/history/audit; domain adapter chịu trách nhiệm phát event creation tương ứng trong cùng UoW khi module được triển khai. Metadata/association chưa phát arbitrary workflow event.

SRC-017 exposes [assignment/target/history APIs](routing.md) over installed subtype adapters. Conversation assigned callback cancels queued outbound; takeover uses its own permission, no implicit assign grant. Reason codes, service actor attribution and eligibility ports are implemented; older SRC-010 notes above describe that earlier release only.
