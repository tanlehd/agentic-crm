## Typed adapter contract

Internal server-only port describe(context) -> immutable SnapshotManifest; page(context,snapshotId,pageNumber) -> Observation[]. Context explicitly supplies business tenantId, bindingId UUID, environment=mock, adapterId=synthetic_g1_v1. Reject missing/system/zero tenants. Local operator/test invokes ingestion, no public endpoints or report-design ingestion grant. The port does not authenticate a caller; future query/HTTP adapter must resolve trusted native source row/field access before delivering facts. No cross-service SQL/FK/domain imports.

Manifest schemaVersion1 binds context, snapshotId SHA256, full catalog/catalogHash, observedThrough/historyFrom actual UTC ISO timestamps, availableFields, pageHashes[], observationCount. snapshotId hashes all other manifest properties. Max10000 observations,200 pages,100 observations/page,128KiB/page,2048chars/scalar. Complete snapshot only. Adapter clones immutable data; numbered pages bound to content hash, context and snapshot. IDs are ASCII strings, not JS numbers; equal source IDs across tenants allowed.

Observation exact shape {object,id,revision,deleted,observedAt,values}. Revision positive decimal string<=16digits scoped to object+id. values contains exactly that object's fully qualified descriptor fields; reference/string/enum bounded strings, safe integers, decimal/money canonical strings max14 integer/6 fractional digits, real UTC millisecond ISO datetime, boolean. Null is unknown/not-applicable, never zero. Key field equals id; tombstone has empty values. Unknown envelopes/fields/types fail closed. Persist descriptor-validated JSON, not arbitrary SQL or formulas. Typed SQL field indexes/query materialization is a SRC-059 decision.

Synthetic catalog independently extends a clone of catalogV1; published catalogV1 is unchanged. All19 original objects/85 fields/four models plus message,assignment,team_membership,creative_media_link,lead_event,deal_event. Explicit grains preserve message delivery/kind/Human-AI author, historical role/team/Lead/Deal changes, reused Creative/two media without multiplying facts. No transcript/credentials/blob fields. G1 five sessions/four threads/four Contacts/four Leads/three won Deals=400USD; A/B/C base spend100/50/25, no session for C; A age60+40/region70+30, latency10/30/50s and two unanswered. Fixture verifies initial owner and latency against events. Old A Insights revision, duplicate/out-of-order revision and deleted obsolete Post exercise reconciliation. Logical references may remain unresolved; don't drop unknown sources or infer attribution. Synthetic field support never claims connected coverage.

## Durable generations

begin(manifest) validates catalog/context/hash and creates staging generation capturing binding revision under binding lock. append(page) locks binding then generation, checks page hash/number/types, accepts next page or exact receipt replay. Atomic observations+receipt+checkpoint; duplicate object/id/revision must match full observation hash, conflicting values reject. Highest numeric revision canonical; tombstone prevents lower-revision resurrection. Immutable observations retain older revisions.

activate requires all pages/exact observation count and captured binding revision CAS. Atomic ready-state+active pointer+minimized activation audit. Staging unreadable, previous active remains during rebuild, old ready generations retained/addressable after switch. Current generation activation retry idempotent; two builds at same base revision have one winner. Stale build returns GENERATION_CONFLICT; retry requires a new explicit manifest, never editing old generations. No adapter/network call inside SQL transaction. Restart resumes persisted next_page; receipts reconcile lost ACK. No truncate/reset/daemon/deletes.

Internal read(context,generation?) resolves active or pinned ready generation, returns Binding(environment=mock,revision=snapshotId), catalog, coverage and canonical nondeleted observations; bounded10000 in-memory canonicalization. This is not a user query/ACL endpoint. Query/source field rights and as-of event semantics are later gates; current source values never substitute for historical lifecycle events.

## Acceptance

Strict type/null/money/time/coverage/hash/context; immutable adapter paging; missing/out-of-order page; duplicate/lower/equal-conflicting revisions; highest tombstone; concurrent/stale activation; staging denied/old snapshot retained; crash/reconnect checkpoint/lost ACK; tenant isolation and runtime grant negatives; forward migration preserves old rows/checksums.
