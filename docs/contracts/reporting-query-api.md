## Native route and source policy

POST /api/v1/reporting/query accepts strict {definition,generation?,format?}; format=json (default) or csv, generation=64 lowercase hex snapshot ID. Definition is the existing schema1 semantic definition, with a durable UUID bindingId. No tenant/principal/permission/limits in body or query parameters. Public parser bound100KiB; serialized BFF/private request96KiB; definition64KiB/depth12. Read-only preview; no idempotency key or draft mutation. Saved drafts remain unvalidated/nonexecutable until a separate authorized preview is requested. Native cookie, matching Origin and CSRF are mandatory, including CSV. X-Tenant-Id selects an active native membership. Missing/malformed cookie is rejected by the existing CSRF guard with403; a valid-shaped but expired/revoked session returns401.

Reviewed native resource report_definition adds run/export actions requiring read seat capability; ephemeral preview requires explicit all-scope run, plus all-scope export for CSV. Existing read/design grants do not imply run/export. New report_mock_source/read/all is an explicit grant to every field and row in all synthetic_g1_v1 mock bindings of that tenant, including future descriptor extensions. Own/team grants do not authorize this tenant-wide fixture; mock agent/team aliases cannot be matched to native principals. No role/default grant is automatically updated. This deliberate complete-fixture policy is distinct from connected CRM/Marketing row/field policies, which remain unsupported and fail closed. Narrower mock scopes require a later policy contract rather than treating hidden outcomes as zero.

Identity resolves seat/grants in a short own-service transaction, then releases it before HTTP. BFF signs audience=reporting-query-v1, tenant/principal/auth revision, mockSource=all, canExport, exact request body hash, issuedAt/expiresAt(max5s). Separate audience prevents using draft admission on query or vice versa. Same operator signing key/config as existing bridge; no client URL accepted. Before public delivery BFF reloads current Identity permissions and expected principal/revision and controller rechecks native session. Revocation during execution therefore denies result release, including cache/CSV. Private admission has bounded5s validity, not cross-service linearizable revocation.

## Private execution and response

POST /internal/v1/reporting/query accepts the same body and signed header; cookies/Origin/X-Tenant-Id/query strings rejected. Validate exact request, signature/body/expiry and export grant before own-store access. Resolve only tenant-scoped ready mock generations through ProjectionStore; connected/environment mismatch and missing foreign binding are404. No producer SQL or source-domain imports. Construct full-field/full-row QueryAccess only from the verified complete-mock grant and selected immutable catalog, then call existing QueryRunner. Share cache and tenant concurrency across requests per service instance; isolate each request's assertion/snapshot. Recheck assertion expiry before delivery.

JSON success {data:QueryResult,meta:{correlation_id}}; CSV success text/csv;charset=utf-8, attachment filename report.csv, X-Correlation-Id header. Both no-store/nosniff. Private transport always returns JSON {data:QueryResult|string,meta}; BFF buffers bounded response (4MiB JSON wrapper limit; aggregate core2MiB) and releases only after live checks. Backend fetch4500ms, signed lifetime5000ms, synchronous executor cooperative3000ms. Client disconnect stops public delivery; durable cancellation/run state remains future scope.

Errors:400 invalid shape/semantic definition or unsupported execution;401 native session/admission invalid;403 permission/stale authorization;404 unavailable binding/generation;409 snapshot unavailable/not ready;422 inconsistent source values/coverage/currency;429 tenant concurrency;503 dependency unavailable;504 execution deadline. Sanitize unexpected errors; do not return records, SQL, token or credential data. Admission expiry fails even on cache hit. Body-parser failures contain no submitted body snippets. Public error envelope remains {error:{code,retryable},meta:{correlation_id}}.
