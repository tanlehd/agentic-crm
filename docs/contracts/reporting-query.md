## Rights and delivery

Base rows may be restricted by an explicit allowed-ID set. Every object/field needed by compiler and execution (including hidden join/time/ID/currency dependencies) must be granted and covered. Non-base related/child objects require complete authorized population ('all') in this phase; partial Lead/Deal scope rejects SOURCE_SCOPE_INCOMPLETE independently of whether hidden records happen to match. Never convert hidden outcomes to zero or expose diagnostics identifying hidden records. Future native policy adapter must resolve true source rights; mock agent aliases must not be interpreted as native principal IDs.

QueryRunner has separate asynchronous authorize and loadSnapshot ports. Authorize before load/run/cache and again before releasing results or CSV; authority revision, expiry and full scope fingerprint must match or deny. No SQL UoW across ports. Cache max16 aggregate results keyed by definition+snapshot+catalog+tenant+principal+auth+actual row/field policy hash; never record rows. Re-authorize cache hits; clone cached values, eviction oldest. Concurrent requests2 per tenant, rejects excess, releases slots finally. Cache does not grant permission. Native cookie/CSRF/Identity→signed query assertion and connected source policy adapters are not implemented in this phase; no public route exposes trustedAccess.
