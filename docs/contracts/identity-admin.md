# Identity admin — exact M1 contract

Status: Ready for implementation SRC-007 B/C. CHG-20261003-06. Routes theo [API](api.md), schema máy đọc trong packages/contracts/schemas/identity-admin.json.

- POST membership: account_id UUID tồn tại, seat_code enum viewer/chat/sales/service/admin, role_ids/team_ids UUID arrays unique tối đa 100; status luôn active, principal human sinh atomic. PATCH: seat_code/status(active/suspended)/role_ids/team_ids optional, ít nhất một field. Array replacement; [] xóa assignments. Không nhận tenant_id/principal kind/ref.
- POST team: name nonblank max255, purpose chat/sales/service/general. PATCH name/active boolean. POST role: key `[a-z][a-z0-9_]{0,63}`, name, permissions array tối đa 200 `{resource,action,scope:own|team|all}`; PATCH name/permissions. Không wildcard. Unknown action được lưu cho module tương lai nhưng không được authorization core cấp quyền.
- POST ai-agents: name, policy_id cùng tenant, runtime_adapter key, max_concurrency integer 1..10000, role_ids/team_ids. PATCH name/policy_id/max_concurrency/role_ids/team_ids. Principal ai active sinh atomic. PATCH principals: availability available/unavailable hoặc status active/suspended (status chỉ AI). Permission theo kind. Không có DELETE hoặc public bootstrap.
- GET collections: limit 1..100 (default50), cursor HMAC chứa account/tenant/resource/status/position `(created_at,id)`; membership filter status optional. Foreign/tampered cursor 400. GET /me/memberships chỉ active membership/principal + tenant active của session account, cùng pagination; không cần tenant header. Tenant switch là đổi X-Tenant-Id từng request, không lưu tenant vào session.
- Response entity: UUID id/tenant_id, version string positive decimal; các field nghiệp vụ như request, membership/AI thêm principal_id, principal_version, auth_revision, role_ids/team_ids; principal có kind/status/availability/auth_revision. Không expose issuer/subject/email, policy tools hoặc credential. Envelope data/meta.correlation_id, collection next_cursor nullable top-level. Mutation ETag quoted version. Không có GET individual trong scope này.
- JSON unknown fields/null/empty PATCH reject400. UUID, positive version và Idempotency-Key kiểm trước DB. Missing If-Match428, stale409, unavailable foreign references404, duplicate409. Same idempotency hash trả nguyên body/correlation/status/ETag; replay vẫn đòi current action + read quyền. Hash canonical body + If-Match; different hash409. Key scope tenant/actor/method+path/key.
- Last-admin: tenant phải còn ít nhất một active Human + active membership seat admin + role key tenant_admin và effective read/create/update all trên membership,role,team,agent. Role union được tính, không coi role name đơn thuần đủ. Kiểm sau mọi mutation trong cùng transaction; tenant_admin role permissions không được sửa làm mất admin cuối. Hai demotion cạnh tranh serialize bởi tenant FOR UPDATE. Thiếu admin ban đầu chỉ bootstrap nội bộ được sửa, không có bypass public.
- Đổi membership/AI config, principal status/availability hoặc role/team definition tăng affected principal auth_revision + version; membership auth_revision tăng cùng transaction, membership version tăng khi PATCH membership. Role change tăng service_actor.auth_revision. Ghi principal.access_changed cho từng principal; service actor revision được kiểm trực tiếp khi dispatch, không giả service actor là principal.
- Mutation commit cùng audit (field names, không values/PII), outbox và idempotency receipt qua kernel port. Sensitive permission/last-admin/stale rejection có denied audit tách transaction sau rollback, chỉ IDs/action/code. SRC-008 tiếp tục publish/consume/leases và privilege hardening; không tự dispatch ở SRC-007.
- Read APIs và writes xác thực session, tenant active, seat+role. CSRF/Origin bắt buộc writes. No-store tất cả response. Field policy storage/query/export chưa có ở Identity task; không mở CRM endpoints.
