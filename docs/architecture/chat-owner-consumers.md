## Internal operation distinctions

Machine schemas express protocol shape; semantic validation remains mandatory. Caller allowlist is an upper bound; Human-only workspace commands reject service/AI actor even via BFF. A workflow may invoke only its pinned typed action mapping, not arbitrary compat routes. Prompt-submit requires AI owner; Human message endpoints reject AI actor. `command-abort` cannot abort a parent with unresolved admitted child; recurse terminal proofs first. `capacity-confirm` fetches original owner proofs; caller-supplied snapshots are constraints, never trusted authority. Same-key/different-binding conflicts before effect. Unmounted contribution-apply is not an implementation requirement.

For storage mapping T02 receives [logical additions and compatibility keys](../contracts/chat-owner-v1.md#compatibility-and-storage-handoff), existing36Chat tables+8partitions and the127-table audit. It must fill concrete templates and four-ledger predicates; T01 deliberately does not claim D3-01 or physical readiness.
