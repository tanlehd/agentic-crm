Queries/counts use a local repeatable-read snapshot, bounded scans through application ports, Unicode NFC/lowercase name prefix, live signed keyset cursors and per-viewer unread. Only queue/read-state capabilities are enabled when schema/backfill are ready. Registered read-marker event validator prevents unsupported worker delivery. Strict JSON Schema/OpenAPI/generated clients included.

Upgrade requires quiescing writers before schema20 DDL/cutoff capture, then running migration CLI backfill before enabling clients. Backfill reads200 messages at a time and commits per Conversation under the existing registry lock; a failed Conversation transaction can be retried. No reset or destructive rollback. Old schema writers retain compatibility; this is not permission to roll back to an old writer after activating new features.
