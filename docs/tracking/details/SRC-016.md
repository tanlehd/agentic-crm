Owner: Codex 2026-10-05. Status: DONE. Dependency SRC-015 DONE. Working tree on `main` after `8cceb22`; existing SRC-015 edits preserved. No commit/push/deploy.

## Implementation

- Chat tab: real queue state/mine/unassigned/team filter, prefix search on loaded pages, cursor loading, latest-message preview, Contact and CTM context, Human/AI owner and delivery status.
- Timeline and internal notes load from APIs; TanStack Query polls loaded pages every 5 seconds while inbox is open, pauses background polling. Note creation does not require ownership; reading applies independent Activity scope/field ACL.
- Quick reply inserts editable text. Composer follows backend allowed_actions; owner revision change requires explicit review. Review state, drafts, keys and ambiguous send payload remain in tenant-scoped memory across detail navigation/errors. Tenant switching destroys prior workspace/cache.
- Lost ACK retains exact text/owner_revision/idempotency key. Explicit check repeats that request, without silently issuing a new send. Unknown delivery shows warning with no resend control. Closed detail is read-only.
- Additive optional Conversation projection and GET notes; no migration. Identity supplies owner kind through a port; CRM supplies notes through a port. Receipt replay rechecks field access to latest-message snapshot.
- Local seed adds inbox_operator once for Alpha/Beta admins; repeat preserves revoked role binding/permissions. Browser ownership harness only mutates `src016-synthetic-` records through registry/UoW/audit/cancel hook; no public assignment route.
