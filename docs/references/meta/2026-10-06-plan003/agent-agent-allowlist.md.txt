

# Agent Allowlist

Manage the consumer allowlist for the AI agent on a specific entity.

This endpoint manages the consumer allowlist for the AI agent on a specific entity. When the AIAudience setting is set to ALLOWLISTED_ONLY, the agent only responds to consumers whose identifiers are in this list. Uses POST to add entries, GET to list all entries, and DELETE to remove individual entries. Adding, listing, and removing entries are each rate limited to 1,000 requests per hour for each app, counted separately per operation. Exceeding a limit returns `429 Too Many Requests`. These limits are subject to change.

  - Permission: whatsapp_business_messaging
  - Permission: instagram_basic

## POST /

Add to allowlist

Add a consumer to the allowlist for the specified entity. A WhatsApp business phone number can hold up to 20 allowlisted consumer phone numbers, and an Instagram business account can hold up to 20 allowlisted Instagram accounts. The two limits are counted separately. Adding an entry once the allowlist is full returns `400 Bad Request`, and the error detail reports the current maximum.

# Components

## Schemas

&lt;jumplink id=&quot;bizaiomnichannelallowlistrequestv2&quot;&gt;&lt;/jumplink&gt;
### BizAIOmniChannelAllowlistRequestV2

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| consumer_phone_number | string |  | Consumer WhatsApp phone number in E.164 format. Required when the entity is a WhatsApp business phone number, and must be omitted for Instagram business assets. Mutually exclusive with `consumer_instagram_username`. |
| consumer_instagram_username | string |  | Instagram username for the consumer, without the leading `&#064;`. Required when the entity is an Instagram business asset, and must be omitted for WhatsApp business phone numbers. Mutually exclusive with `consumer_phone_number`. |

&lt;jumplink id=&quot;bizaiomnichannelallowlistresponsev2&quot;&gt;&lt;/jumplink&gt;
### BizAIOmniChannelAllowlistResponseV2

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| id | string | ✓ | The unique identifier for this allowlist entry. Pass this value unchanged as the `entry_id` path parameter to remove the entry. |
| consumer_phone_number | string |  | Consumer WhatsApp phone number in E.164 format. Present only on entries for WhatsApp business phone number entities. Mutually exclusive with `consumer_instagram_username`. |
| consumer_instagram_username | string |  | Current Instagram username for the consumer. Present on Instagram entries when the account is available. Mutually exclusive with `consumer_phone_number`. |
