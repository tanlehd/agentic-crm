

# Agent Knowledge - Files

Manage file-based knowledge sources for the AI agent on a specific entity.

This endpoint provides operations for managing file-based knowledge sources in the AI agent knowledge base for a specific entity. Files such as PDFs, text documents, or other supported formats can be uploaded to supplement the agent&#039;s knowledge. Supports uploading, listing, retrieving, and deleting files. Every operation on this resource shares a budget of 1000 requests per hour; once it is exhausted, further requests return `429` until the limit resets.

## Base URL

## POST /

Upload a knowledge file

Upload a document to the agent&#039;s knowledge base. Use files for unstructured reference material that is too long or too varied to express as FAQ entries, such as product guides, policy documents, and price lists. The agent draws on file contents when no FAQ entry matches the customer&#039;s question. See the `file` field for the supported formats and the maximum file size.

## Schemas

&lt;jumplink id=&quot;bizaiomnichannelknowledgefilerequest&quot;&gt;&lt;/jumplink&gt;
### BizAIOmniChannelKnowledgeFileRequest

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| file_name | string | ✓ | The name of the file being uploaded. Include the file extension. The extension must match the content of the uploaded file, and it selects the type for file formats that cannot be identified from their content, such as .csv, .doc, .docx, and .xlsx. A request whose extension contradicts the uploaded content is rejected, and so is a request whose extension names an unsupported type. If you omit the extension and the content identifies the format, the response returns the name with the matching extension added. Use the returned name when you read or delete the file. |
| file | string (binary) | ✓ | The file to be uploaded. The content is checked against the extension declared in file_name. Maximum file size: 100000000 bytes. Supported file types: - .pdf - .doc - .docx - .png - .jpg - .jpeg - .csv, when CSV extraction is enabled for the WhatsApp asset - .xlsx, when XLSX extraction is enabled for the WhatsApp asset |
