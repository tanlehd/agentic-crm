

# Agent Knowledge - Websites

Manage website URLs for AI agent knowledge crawling.

This endpoint provides CRUD operations for managing website URLs that the AI agent should crawl and ingest into its knowledge base. Businesses can submit website URLs and the system crawls and extracts content from these websites to supplement the agent&#039;s knowledge when responding to customer queries. Websites are periodically recrawled to ensure the agent&#039;s knowledge remains up to date. Every operation on this resource shares a budget of 1000 requests per hour; once it is exhausted, further requests return `429` until the limit resets.

## POST /

Add a knowledge website

Register a website for the agent to crawl into its knowledge base. By default the whole domain at `url` is crawled. Use the subdomain, URL-pattern, and single-URL fields to narrow that scope. Narrowing matters most for multi-region and multi-language sites, where crawling everything gives the agent contradictory content, such as prices or policies from a market the customer is not in.

# Components

## Schemas

&lt;jumplink id=&quot;bizaiknowledgewebsiterequest&quot;&gt;&lt;/jumplink&gt;
### BizAIKnowledgeWebsiteRequest

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| url | string | ✓ | The URL of the website to crawl |
| included_sub_domains | array of string |  | Restrict crawling to these subdomains. When set, only pages on these subdomains are added to the knowledge base. |
| included_url_patterns | array of string |  | Restrict crawling to URLs containing these patterns. When set, only matching pages are added to the knowledge base. |
| excluded_sub_domains | array of string |  | Subdomains to exclude from the knowledge base. |
| excluded_url_patterns | array of string |  | URL patterns to exclude from the knowledge base. Any URL containing one of these substrings is skipped. |
| single_urls | array of string |  | Crawl only these exact URLs instead of the whole website domain. |

&lt;jumplink id=&quot;bizaiknowledgewebsiteresponse&quot;&gt;&lt;/jumplink&gt;
### BizAIKnowledgeWebsiteResponse

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| id | string | ✓ | The unique identifier for this website crawl entry. Pass this value unchanged as the `website_id` path parameter to read, update, or delete the entry. |
| url | string | ✓ | The URL of the website being crawled |
| crawl_status | string |  | The current status of the crawl: &quot;not_started&quot;, &quot;pending&quot;, &quot;in_progress&quot;, &quot;completed&quot; (we crawled the site and extracted knowledge), &quot;completed_no_data&quot; (we crawled it successfully but found nothing extractable) or &quot;failed&quot; (the crawl itself did not fetch any pages -- see crawl_error). |
| crawl_error | string |  | A human-readable explanation of why the crawl failed, for example the site being unreachable or blocking our crawler in robots.txt. Empty while a crawl is still running, and empty for a crawl that fetched pages -- crawl_status already says whether anything was extractable. |
| pages_crawled | integer |  | The number of pages successfully crawled |
| last_crawled_at | integer |  | The timestamp when the website was last successfully crawled |
| created_at | integer |  | The timestamp when the website entry was created |
| included_sub_domains | array of string |  | Subdomains crawling is restricted to, if any |
| included_url_patterns | array of string |  | URL patterns crawling is restricted to, if any |
| excluded_sub_domains | array of string |  | Subdomains excluded from the knowledge base, if any |
| excluded_url_patterns | array of string |  | URL patterns excluded from the knowledge base, if any |
| single_urls | array of string |  | Exact URLs crawled instead of the whole domain, if any |
