## Subscribing to standby webhooks

To receive standby webhooks, subscribe to the `standby` field in your app&#039;s Webhooks configuration:

1. Go to your app in the [Meta Developer Portal](https://developers.facebook.com/apps).
2. Navigate to **WhatsApp &gt; Configuration &gt; Webhook fields**.
3. Subscribe to the **standby** field.

## Payload structure

### Common envelope

Every standby webhook uses this envelope:

```html
&#123;
  &quot;object&quot;: &quot;whatsapp_business_account&quot;,
  &quot;entry&quot;: [
    &#123;
      &quot;id&quot;: &quot;&lt;WHATSAPP_BUSINESS_ACCOUNT_ID&gt;&quot;,
      &quot;changes&quot;: [
        &#123;
          &quot;value&quot;: &#123;
            &quot;messaging_product&quot;: &quot;whatsapp&quot;,
            &quot;metadata&quot;: &#123;
              &quot;display_phone_number&quot;: &quot;&lt;BUSINESS_PHONE_NUMBER&gt;&quot;,
              &quot;phone_number_id&quot;: &quot;&lt;PHONE_NUMBER_ID&gt;&quot;
            &#125;,
            &quot;standby&quot;: &#123;&#125;
          &#125;,
          &quot;field&quot;: &quot;standby&quot;
        &#125;
      ]
    &#125;
  ]
&#125;
```

The `standby` object contains one of: `messages`, `message_echoes`, or `statuses`.

### Parameters

| Name | Type | Description |
|------|------|-------------|
| `standby.contacts` | array | Array of contact objects describing the message sender. |
| `standby.contacts[].profile.name` | string | The WhatsApp user&#039;s profile name. |
| `standby.contacts[].wa_id` | string | The WhatsApp user&#039;s WhatsApp ID (phone number). |
| `standby.messages` | array | Array of message objects. |
| `standby.messages[].from` | string | Sender&#039;s WhatsApp ID. |
| `standby.messages[].id` | string | Unique message identifier (`wamid.*`). |
| `standby.messages[].timestamp` | string | Unix epoch timestamp in seconds. |
| `standby.messages[].type` | string | Message type — for example, `text`, `image`, `document`, `audio`, `video`, `location`, `contacts`, `interactive`, `button`, `reaction`. |
| `standby.messages[].text.body` | string | Text content (present when `type` is `text`). |

**Note:** All message types supported by WhatsApp (such as image, document, audio, video, location, contacts, interactive, and reaction) are delivered in standby using the same schema as [standard incoming message webhooks](https://developers.facebook.com/documentation/business-messaging/whatsapp/webhooks/reference/messages). The example above shows a `text` message; other types include their respective content objects.

### Template message echo

For template messages, the echo contains two template-related objects:

- **`message.template`** — The send-time parameters (template name, language, component variable values) as passed to the [Send Message API](https://developers.facebook.com/documentation/business-messaging/whatsapp/reference/whatsapp-business-phone-number/message-api#message-templates). This tells you *what values* were substituted.
- **`template`** (sibling of `message`, inside each echo object) — The full unhydrated template definition, matching the format described in [Templates overview](https://developers.facebook.com/documentation/business-messaging/whatsapp/templates/overview). This tells you the *template structure* with placeholder markers (for example, `&#123;&#123;1&#125;&#125;`), not the rendered text.

**Note:** Use the sibling `template` object to understand the template layout, and `message.template` to see which parameter values were filled in at send time.

### Parameters

| Name | Type | Description |
|------|------|-------------|
| `standby.message_echoes` | array | Array of echo objects. |
| `standby.message_echoes[].id` | string | Unique message ID (`wamid.*`) assigned at send time. |
| `standby.message_echoes[].timestamp` | string | Unix epoch in seconds when the message was sent. |
| `standby.message_echoes[].message` | object | The exact request body as passed to [POST /&#123;phone-number-id&#125;/messages](https://developers.facebook.com/documentation/business-messaging/whatsapp/reference/whatsapp-business-phone-number/message-api). Contains all send-time parameters. |
| `standby.message_echoes[].template` | object | *(Optional)* Present only for template messages. The full unhydrated template definition. See [Templates overview](https://developers.facebook.com/documentation/business-messaging/whatsapp/templates/overview). |
| `standby.message_echoes[].flow` | object | *(Optional)* Present only for flow messages. The full flow definition as returned by GET /&#123;flow-id&#125;. |

**Note:** For template messages, `message.template` carries only the send-time **parameters** (variable values) — see [Cloud API — Send message templates](https://developers.facebook.com/documentation/business-messaging/whatsapp/reference/whatsapp-business-phone-number/message-api#message-templates). The sibling `template` object contains the full template definition format as described in [Templates overview](https://developers.facebook.com/documentation/business-messaging/whatsapp/templates/overview).

## Standby status receipt

### Example payload

```html
&#123;
  &quot;object&quot;: &quot;whatsapp_business_account&quot;,
  &quot;entry&quot;: [
    &#123;
      &quot;id&quot;: &quot;&lt;WHATSAPP_BUSINESS_ACCOUNT_ID&gt;&quot;,
      &quot;changes&quot;: [
        &#123;
          &quot;value&quot;: &#123;
            &quot;messaging_product&quot;: &quot;whatsapp&quot;,
            &quot;metadata&quot;: &#123;
              &quot;display_phone_number&quot;: &quot;&lt;BUSINESS_PHONE_NUMBER&gt;&quot;,
              &quot;phone_number_id&quot;: &quot;&lt;PHONE_NUMBER_ID&gt;&quot;
            &#125;,
            &quot;standby&quot;: &#123;
              &quot;statuses&quot;: [
                &#123;
                  &quot;id&quot;: &quot;&lt;MESSAGE_ID&gt;&quot;,
                  &quot;status&quot;: &quot;delivered&quot;,
                  &quot;timestamp&quot;: &quot;&lt;TIMESTAMP&gt;&quot;,
                  &quot;recipient_id&quot;: &quot;&lt;RECIPIENT_WA_ID&gt;&quot;,
                  &quot;conversation&quot;: &#123;
                    &quot;id&quot;: &quot;&lt;CONVERSATION_ID&gt;&quot;,
                    &quot;origin&quot;: &#123;
                      &quot;type&quot;: &quot;utility&quot;
                    &#125;
                  &#125;,
                  &quot;pricing&quot;: &#123;
                    &quot;billable&quot;: true,
                    &quot;pricing_model&quot;: &quot;PMP&quot;,
                    &quot;category&quot;: &quot;utility&quot;,
                    &quot;type&quot;: &quot;regular&quot;
                  &#125;
                &#125;
              ]
            &#125;
          &#125;,
          &quot;field&quot;: &quot;standby&quot;
        &#125;
      ]
    &#125;
  ]
&#125;
```

### Parameters

| Name | Type | Description |
|------|------|-------------|
| `standby.statuses` | array | Array of status objects. |
| `standby.statuses[].id` | string | The message ID this status refers to. |
| `standby.statuses[].status` | string | Delivery status: `sent`, `delivered`, or `read`. |
| `standby.statuses[].timestamp` | string | Unix epoch in seconds of the status event. |
| `standby.statuses[].recipient_id` | string | WhatsApp ID of the message recipient. |
| `standby.statuses[].conversation.id` | string | Conversation ID. |
| `standby.statuses[].conversation.origin.type` | string | Conversation origin: `utility`, `marketing`, `authentication`, `service`, or `referral_conversion`. |
| `standby.statuses[].pricing.billable` | boolean | Whether this message is billable. |
| `standby.statuses[].pricing.pricing_model` | string | Pricing model (for example, `PMP`). |
| `standby.statuses[].pricing.category` | string | Pricing category. |
| `standby.statuses[].pricing.type` | string | Pricing type (for example, `regular`). |
