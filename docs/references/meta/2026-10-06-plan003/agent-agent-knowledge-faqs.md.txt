

# Agent Knowledge - FAQs

Manage FAQ entries in the AI agent knowledge base for a specific entity.

This endpoint provides CRUD operations for managing FAQ entries in the AI agent knowledge base for a specific entity. FAQs are question-answer pairs that the agent references when responding to customer queries. Each FAQ entry has a `question`, an `answer`, and optional key-value `metadata`. Responses also carry the entry&#039;s `id` and its creation timestamp. For best results, keep FAQs focused and concise. Each entry should address a single, specific question. Adding too many FAQs (generally beyond a few hundred) can degrade the agent&#039;s ability to find the right answer. Prioritize the questions your customers ask most frequently and keep answers factual and direct. Every operation on this resource shares a budget of 1000 requests per hour; once it is exhausted, further requests return `429` until the limit resets.

Delete an FAQ entry by its ID. The agent stops answering from it. Other knowledge sources for the entity are unaffected.

| faq_id | string | ✓ | The identifier of the FAQ entry, as returned in the `id` field when the entry was created or listed. Pass that value through unchanged. |

Create an FAQ

Create an FAQ entry: a question-and-answer pair the agent can use to answer a specific customer question. FAQs are the most direct way to control how the agent answers a known question. The agent retrieves each entry independently and answers from it, rather than inferring an answer from your other knowledge sources.

## Schemas

&lt;jumplink id=&quot;bizaiomnichannelknowledgefaqrequest&quot;&gt;&lt;/jumplink&gt;
### BizAIOmniChannelKnowledgeFAQRequest

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| question | string | ✓ | The FAQ question text. Write it as a natural question a customer would ask. Each FAQ should address a single, specific topic. For example, use &quot;What is your return policy?&quot; rather than &quot;Returns, exchanges, and refunds&quot; — the agent matches questions more accurately when they mirror how customers phrase them. |
| answer | string | ✓ | The FAQ answer text. Keep answers factual, concise, and self-contained. Include all the information needed to fully answer the question without requiring the customer to ask follow-ups. Avoid referencing other FAQ entries — the agent retrieves each entry independently. |
| metadata | [Metadata](#object-metadata-1) |  | Key-value metadata associated with this FAQ entry |
