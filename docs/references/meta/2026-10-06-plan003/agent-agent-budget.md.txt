

# Agent Budget

Cap business-agent usage so costs and conversation length stay predictable.

A budget caps agent usage within a rolling time window. Use these endpoints to read the budgets configured for an agent and to replace them.

Each budget is a combination of three things:

- `unit_type` — what is being measured: token usage across the Business Manager or AI agent turns within each conversation.
- `time_window` — the period the usage is totalled over: one day, seven days, fourteen days, or thirty days. Windows roll rather than resetting on a fixed calendar boundary, and are measured in the timezone of the WhatsApp Business Account.
- `max_budget` — the maximum allowed usage in that window.

You can configure several budgets at once — for example a one-day token cap alongside a one-day AI-turn cap and longer rolling caps. A given `unit_type` and `time_window` pair may only appear once; a request containing two budgets for the same pair is rejected. To raise or lower an existing cap, edit that budget rather than adding a second one for the same window.

When more than one budget is configured, whichever is reached first takes effect. Once a budget is reached the agent completes the turn it is already working on, then stops replying to new messages and hands the conversation to a human using the routing the agent is already set up with. Replies resume once the time window rolls over.

An agent with no budgets configured has unlimited usage.

Reading and replacing budgets share a budget of their own: 1000 requests per hour across both endpoints. Once it is exhausted, further requests return `429` until the limit resets. This is a limit on calls to these endpoints and is unrelated to the spend budgets they configure.

## GET /

Get the agent budgets

Retrieve every budget currently configured for the agent. An empty `budgets` array means no cap is set and usage is unlimited.

## POST /

Replace the agent budgets

Replace the full set of budgets for the agent. The request describes the complete desired state, so any budget you leave out is removed, and an empty `budgets` array clears every budget and returns the agent to unlimited usage.

To change an existing budget, pass back the `budget_id` that was returned for it; the budget is updated in place and keeps its id. Omit `budget_id` to add a new budget and have an id assigned.
