

# Agent Onboarding

Trigger AI agent onboarding for a specific entity.

This endpoint triggers the onboarding flow for a Business AI agent on a specific entity. It creates the necessary entities and schedules async jobs for data preparation. An optional catalog can be linked during onboarding.

## Base URL

| URL | Description |
|-----|-------------|
| https://api.facebook.com/&#123;entity_id&#125;/agent_onboarding |  |

## Authorization

This API requires:

any of the following
  - Capability: bizai_wa_enterprise_api_3p_access
  - Capability: bizai_ig_enterprise_api_3p_access
  - Permission: whatsapp_business_messaging

## POST /

Create an onboarding session

Trigger AI agent onboarding for the specified entity. Creates the necessary entities and schedules async jobs for data preparation. An optional catalog can be linked during onboarding.

| Name | Type | Required | Description |
