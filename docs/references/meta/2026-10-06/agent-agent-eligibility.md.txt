

# Agent Eligibility

Check whether a WhatsApp or Instagram business entity is eligible for the business AI agent.

This endpoint reports whether the business AI agent can be enabled for a WhatsApp Business Phone Number or Instagram business account. The resource is a singleton — one eligibility result per entity_id.

## GET /

Get agent eligibility

Check whether the business AI agent can be enabled for a specific WhatsApp Business phone number or Instagram business account. Call this before onboarding, so an entity that cannot use the agent fails fast instead of erroring partway through setup.

For WhatsApp, pass the Business Phone Number ID as `entity_id`. For Instagram, pass the business account ID or username without the leading `&#064;`.

**Check the version header.** Send the `X-API-Version` value shown under Header Parameters below. It does not necessarily match the version used by other Meta Business Agent Platform APIs, so do not reuse a single shared header value across every call.

**When to check.** Use this endpoint to confirm an entity can use the agent before opening its channel management interface. For example, to filter a large set of accounts before onboarding them, to build a self-serve flow where a business connects its own account, or to diagnose why agent onboarding is unavailable for an account.

**Interpreting the result.** The response is a single boolean, so it reports whether the entity is eligible but no reasons if not.

- `true` — the entity can use the agent. Continue with onboarding, then apply agent settings.
- `false` — the entity cannot use the agent. Check the account against the eligibility criteria for its messaging channel.

Eligibility is not permanent. It can change when a business updates its category, or when its standing changes, so re-check an entity rather than caching the result indefinitely.

**An error is not a negative answer.** A `401`, `404`, or `429` means the request could not be evaluated. Do not treat a failed request as &quot;not eligible&quot;.

**Rate limit.** This endpoint allows 1000 requests per hour. Once that is exhausted, further requests return `429` until the limit resets. Eligibility changes slowly, so when you are filtering a large set of accounts, spread the checks across that budget and reuse the result for a while rather than re-checking an entity on every call.
