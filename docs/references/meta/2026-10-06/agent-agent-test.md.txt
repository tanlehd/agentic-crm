

# Agent Test

Send test messages to the AI agent for automated testing.

This endpoint sends test messages to the AI agent for automated testing without requiring a real consumer phone number. Messages are processed through the full agent pipeline and the response is returned synchronously. Use it to validate agent behavior, test knowledge base responses, and verify skill/connector integrations during development. Tokens consumed while testing through this endpoint are not billed. Requests are rate limited to 500 per hour for each `entity_id`, and to 10,000 per hour for each app on this endpoint. Exceeding either limit returns `429 Too Many Requests`. These limits are subject to change.

Run an agent test

Send a test message to the AI agent and receive a response. Messages are processed through the full agent pipeline without requiring a consumer phone number. Tokens consumed while testing through this endpoint are not billed.

# Components

## Schemas

&lt;jumplink id=&quot;bizaiomnichannelagenttestrequest&quot;&gt;&lt;/jumplink&gt;
### BizAIOmniChannelAgentTestRequest

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| user_msg | string | ✓ | The text content of the test message to send to the AI agent |
| conversation_id | string |  | Identifier for multi-turn test conversations. Provide the conversation_id from a previous response to continue that conversation. |

&lt;jumplink id=&quot;bizaiomnichannelagenttestresponse&quot;&gt;&lt;/jumplink&gt;
### BizAIOmniChannelAgentTestResponse

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| message_id | string | ✓ | Unique identifier for this message exchange |
| agent_response | string | ✓ | The AI agent response text |
| conversation_id | string | ✓ | The test conversation identifier. Use this in subsequent requests for multi-turn conversations. |
| timestamp | integer |  | Unix timestamp when the response was generated |
| handoff_reason | string |  | If the agent hands off to a human, this contains the reason |
| no_response_reason | string |  | If the agent did not generate a response, this contains the reason. Possible values include ELIGIBILITY_CHECK_FAILED. |
| quick_replies | array of string |  | Suggested quick reply messages generated by the AI agent |
| product_variant_ids | array of string |  | The variant IDs of the products referenced in the agent response |
