

# Connector Tools

Manage tool (endpoint/operation) definitions for a specific connector.

This endpoint provides CRUD operations for managing tool definitions for a specific connector. Tools define the individual operations (endpoints) available on an external API, including the canonical outbound request definition and user-auth extraction metadata. Each tool must have a descriptive `name` and `description` so the agent knows when and how to use it. In the `request_definition`, define the body schema with explicit field types, descriptions, and required fields rather than using unstructured objects — the agent uses this schema to extract the correct values from the conversation and build valid API requests. Every operation on this resource shares a budget of 1000 requests per hour; once it is exhausted, further requests return `429` until the limit resets.

## POST /

Create a connector tool

Create a tool on the specified connector. A tool is one callable operation against the external API the connector points at: the connector supplies the base URL and authentication, and the tool supplies the specific request to make. During a conversation the agent chooses which tool to invoke based on the tool&#039;s `description`, then builds the call from its `request_definition`. A connector with no tools is never invoked.
