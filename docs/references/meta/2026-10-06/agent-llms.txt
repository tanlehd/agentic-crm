### How-to guides

- [Multi-component single transaction agent](https://developers.facebook.com/documentation/meta-business-agent/usage-guides/single-purchase-transaction-agent.md): Configure connector tools that search several components, price them as one set, and commit them in a single write, using a flight, hotel, and car hire as the example.
- [Booking and reservation agent](https://developers.facebook.com/documentation/meta-business-agent/usage-guides/booking-and-reservation-agent.md): Configure Meta Business Agent to answer vehicle questions, check fleet availability for a date range, create reservations, and report booking status for renters on WhatsApp.
- [Customer support agent](https://developers.facebook.com/documentation/meta-business-agent/usage-guides/customer-support-agent.md): Configure Meta Business Agent to answer retail support questions from your own policies, pull up a shopper&#039;s recent orders, start a return, and raise a ticket when a person is needed.
- [Lead generation agent](https://developers.facebook.com/documentation/meta-business-agent/usage-guides/lead-generation-agent.md): Configure Meta Business Agent to qualify catering and bulk-order inquiries, confirm delivery coverage, and submit complete leads to your CRM from WhatsApp.
- [Single item purchase agent](https://developers.facebook.com/documentation/meta-business-agent/usage-guides/single-item-purchase-agent.md): Configure Meta Business Agent to help shoppers find one product, confirm the right size and color, check live stock, and place a single-item order on WhatsApp.
- [Post-purchase support agent](https://developers.facebook.com/documentation/meta-business-agent/usage-guides/post-purchase-support-agent.md): Configure Meta Business Agent to look up a traveller&#039;s booking, explain fare conditions, change a journey, and report refund status on WhatsApp, with a clean handoff during disruption.
- [Writing interactive messages](https://developers.facebook.com/documentation/meta-business-agent/usage-guides/writing-ui-skills.md): Learn how to write interactive messages for Meta Business Agent and the data each component type needs, such as buttons, images, lists, locations, carousels, and WhatsApp Flows on WhatsApp.
